# Data card

**Dataset:** Delhi-NCR hourly PM2.5, 2019-01-01 – 2025-12-31
**Frozen artefact:** `data/processed/delhi_ncr_pm25_2019_2025.npz`
**Modelling set:** 42 stations (34 Delhi, 4 Noida, 4 Ghaziabad), 61,345 hourly
timestamps, 6 features
**Size on disk:** ~36 MB (float32), regenerable from the scripts below
**Licence of the data:** see *Sources* — the data is **not** redistributed in
this repository. Only the small public station-metadata tables are committed.

---

## 1. What this dataset contains

| Field | Meaning |
|---|---|
| `X_full` | `[T, 42, 6]` input features, hourly: PM2.5, temperature, relative humidity, wind u, wind v, rainfall |
| `y_full` | `[T, 42]` PM2.5 target in µg/m³, log1p-then-z-scored |
| `mask_y` | `[T, 42]` 1 = the hour had a real CPCB reading, 0 = missing |
| `mask_X` | `[T, 42, 6]` same, per feature |
| `coords` | `[42, 2]` latitude, longitude |
| `station_ids` | `[42]` CPCB station identifiers |
| `feature_names` | feature order |
| `norm_mean`, `norm_std` | normalisation statistics, **fitted on the training split only** |
| `split_indices_{train,val,test}` | chronological index blocks |
| `timestamps` | `[T]` unix seconds, local time (IST, UTC+05:30) |

**No synthetic values.** An hour with no real reading stays missing (NaN) and
is flagged in the mask; the target is never imputed. `scripts/provenance.py`
audits the frozen file mechanically and reports zero values present while
flagged unobserved.

## 2. Sources

| what | source | accessed via | licence |
|---|---|---|---|
| hourly PM2.5 target + station meteorology | CPCB continuous monitoring, 15-minute records | <https://github.com/Vonter/india-cpcb-aqi> (release archive) | Open Database Licence (ODbL), as published by CPCB |
| ERA5 reanalysis wind (one ablation only) | ERA5 via the Open-Meteo archive API | <https://archive-api.open-meteo.com/v1/archive> | Copernicus licence (free, non-commercial use) |
| station metadata (id, name, city, lat/lon) | CPCB station list; XKDR air-quality station registry | `data/raw/station_coords.csv`, `data/raw/cpcb_station_catalog.csv` | public reference data |

**Access terms.** The CPCB records are published by the Central Pollution
Control Board under the ODbL, which permits redistribution with attribution
and share-alike. We do not redistribute them here anyway: the files are large
and the repository is easier to use as a set of scripts. The ERA5 files are
under the Copernicus licence, which permits free non-commercial use but asks
users to obtain their own copy; `scripts/fetch_era5_wind.py` does that from a
public API with no registration.

**No API keys are required for any of the fetch scripts.** The CPCB archive is
a GitHub release archive; Open-Meteo is open.

## 3. How to get the data

```bash
# 1. CPCB 15-minute records, 2019-2025  (~1.4 GB, 56 station files)
python scripts/fetch_cpcb_years.py --years 2019 2020 2021 2022 2023 2024 2025

# 2. ERA5 hourly wind for the 42 modelling stations (one ablation only)
python scripts/fetch_era5_wind.py --years 2019 2020 2021 2022 2023 2024 2025

# 3. Build the frozen dataset.
#    This FAILS if any station falls below 70% real-observation coverage in
#    any split, and it never fabricates a value.
python scripts/build_dataset.py
```

Step 3 writes `data/processed/delhi_ncr_pm25_2019_2025.npz` and
`data/processed/coverage_report.csv` (per station, per year, the observed
fraction before any processing). The build is deterministic: the same inputs
give a byte-identical file.

## 4. Coverage

Observed fraction of the (station, hour) grid, before any processing:

| split | hours | observed | missing |
|---|---|---|---|
| train (2019-01-01 → 2022-12-31) | 35,041 | 90.80% | 9.20% |
| validation (2023) | 8,760 | 92.32% | 7.68% |
| test (2024-01-01 → 2025-12-31) | 17,521 | 93.52% | 6.48% |

The full per-station, per-year table is regenerated by `scripts/provenance.py`
into `outputs/provenance.md`.

**Wind coverage caveat.** Nine of the 42 stations (the IMD-operated monitors:
`site_103, 105, 106, 107, 108, 109, 111, 117, 5024`) report no wind at all, in
any year. The wind-aware graph assigns those stations the network-mean wind
direction as a placeholder. The ERA5 ablation exists to test whether that
noisy, partly missing local wind is what makes the wind-aware graph
disappointing.

## 5. Known limitations of the data

- **Single region, single hazard.** Delhi-NCR only, PM2.5 only. Nothing here
  establishes transfer to another city or another pollutant.
- **Station network changes.** The 42 stations are not a fixed panel across the
  whole record; some begin later or stop earlier. The per-year coverage table
  quantifies this.
- **Missingness is not random.** Long outages cluster at particular stations
  and periods, and outages coincide with the high-pollution episodes, so the
  observed remainder is not a random sample of the underlying process. All
  metrics are masked to observed values, which is the best available
  correction, but it does not remove the selection effect.
- **The meteorological features are the stations' own instruments**, not a
  reanalysis. They are locally informative but noisy, and for 9 of 42
  stations the wind is absent entirely.
- **The 15-minute records are aggregated to the hour by taking the reading
  stamped exactly on the hour**, not the mean of the four readings in that
  hour. The hourly series is therefore slightly noisier than a true hourly
  average. The effect is identical for every model and baseline, so it does
  not bias the comparisons.

## 6. What is and is not committed

| committed | not committed |
|---|---|
| `src/`, `scripts/`, `configs/`, `tests/` — all code | `data/raw/cpcb_station_csv/` — the CPCB records |
| `data/raw/stations.csv`, `station_coords.csv`, `cpcb_stations.csv`, `cpcb_station_catalog.csv` — public station metadata | `data/raw/era5_wind/` — the ERA5 extract |
| `EXPERIMENTS.md`, `RESULTS_SUMMARY.md`, `report/report.tex` | `data/processed/*.npz` — the frozen dataset |
| `outputs/provenance.md` — the provenance and mask audit | `checkpoints/*.pt` — model weights |

Everything not committed is regenerable with the commands in §3 followed by
`scripts/train_all.py`.
